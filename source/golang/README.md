# Astronomy Engine for Go

A **native, pure-Go** port of [Astronomy Engine](https://github.com/cosinekitty/astronomy),
a suite of libraries for calculating positions of the Sun, Moon, and planets, and
for predicting interesting events like oppositions, conjunctions, rise and set
times, lunar phases, eclipses, transits, and more.

## Highlights

- **Pure Go**: no CGO, no C wrappers, no external astronomy libraries.
- **Zero dependencies**: only the Go standard library. `go list -m all` shows
  nothing but the module itself.
- **CGO-free**: works with `CGO_ENABLED=0` on machines with no C compiler.
- Requires **Go 1.27** or newer.
- The VSOP87 planetary model, the TOP2013-derived Pluto state table, the
  Jupiter moon ephemerides, and the constellation boundaries are all embedded
  in the source, so there are no external data files at runtime.

## Installation

```bash
go get github.com/cosinekitty/astronomy/source/golang
```

The package requires Go 1.27 or newer. It has no third-party dependencies.

## Quick Example

```go
package main

import (
    "fmt"
    "github.com/cosinekitty/astronomy/source/golang"
)

func main() {
    // The date and time of interest (UTC).
    time := astronomy.TimeFromCalendar(2019, 6, 24, 15, 45, 37.0)

    // Geocentric position of the Moon in the J2000 equatorial frame.
    moon := astronomy.GeoMoon(time)
    fmt.Printf("Moon: x=%.9f y=%.9f z=%.9f AU\n", moon.X, moon.Y, moon.Z)

    // Find the next full moon after this time.
    full, err := astronomy.SearchMoonPhase(180.0, time, 40.0)
    if err != nil {
        fmt.Println(err)
        return
    }
    cal, _ := astronomy.CalendarFromDays(full.Ut)
    fmt.Printf("Next full moon: %04d-%02d-%02d %02d:%02d\n",
        cal.Year, cal.Month, cal.Day, cal.Hour, cal.Minute)
}
```

## Supported Features

- **Time**: UTC/UT, Terrestrial Time (TT), Delta T, calendar conversions,
  sidereal time, current time.
- **Positions**: heliocentric, geocentric, and barycentric position and
  velocity vectors for all planets, the Sun, the Moon, the Earth/Moon
  barycenter, and the Solar System barycenter.
- **Planetary model**: VSOP87 for the eight planets, a TOP2013-derived gravity
  simulation for Pluto, and the Galilean moons of Jupiter.
- **Coordinate systems**: J2000 equator (EQJ), equator of date (EQD), true
  ecliptic of date (ECT), J2000 ecliptic (ECL), horizontal (HOR), and galactic
  (GAL), with rotation matrices and transformations.
- **Observers**: topocentric equatorial and horizontal coordinates, refraction,
  atmospheric density, observer vectors and states, rotation axes of planets,
  constellation lookup.
- **Phenomena**: moon phases, moon quarters, rise/set times, culmination,
  hour angles, equinoxes and solstices, lunar and solar eclipses (global and
  local), transits of Mercury and Venus, lunar apsides, planet apsides,
  lunar nodes, illumination, elongations, relative longitudes, Lagrange points.
- **User-defined stars**: eight user-definable fixed stars with parallax.

## Architecture

The library follows the same architecture as the reference C implementation:

- A single `astronomy` package with value types (`AstroTime`, `AstroVector`,
  `StateVector`, `RotationMatrix`, ...) and idiomatic Go functions.
- Errors are returned as Go `error` values; functions that cannot fail return
  plain values.
- Data tables (VSOP87, Pluto, Jupiter moons, constellation boundaries, Moon
  series) are generated by `generate/codegen.c` from the same raw ephemeris
  files used by the other language ports, so the numbers are bit-identical
  across languages.
- Numerically sensitive operations preserve the original order of operations
  to match the C implementation to double precision.
- Concurrency: the library has no global mutable state except lazily computed
  caches (e.g. Pluto gravity segments) that are safe for single-threaded use;
  independent calculations may be run concurrently.

## Accuracy

The Go implementation is verified against the C implementation and the
Python port to double precision. Representative checks:

| Quantity | Absolute agreement |
|----------|--------------------|
| Heliocentric planet positions | &lt; 1e-14 AU |
| Geocentric Moon position | &lt; 1e-18 AU |
| Geocentric planet positions | &lt; 1e-14 AU |
| Jupiter moon positions | &lt; 1e-18 AU |
| Ecliptic Moon coordinates | &lt; 1e-13 degrees |
| Seasons | &lt; 0.001 seconds |
